# Planned BOY screens

Implement these `.opi` files following [the display plan](../../docs/DISPLAY.md):

- `window_overview.opi`
- `pump_history.opi`
- `input_diagnostics.opi`
- `model_details.opi`
- `window_history.opi`
- `new_window.opi`

This is a scaffold, not a runnable display. The new-window screen must use the
server-enforced arm/token/typed-ID protocol and wait for a durable success receipt.
